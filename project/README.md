# PolynomialTrajectoryPlannerApp

Educational + practical project: analytical generation and analysis of polynomial trajectory profiles (degrees 3, 5, 7, 9, extensible), culminating in a C#/WPF desktop application and a personal theory/knowledge library.

## Repository structure

```
docs/     specification (this is the master input for Trae) + theory library (generated during development)
src/      C#/WPF application (empty for now — created once development starts)
```

## Where to start

`docs/00-vision.md` through `docs/05-success-criteria.md` are the **master specification** — read-only reference, not to be regenerated by the AI assistant, only amended deliberately when a requirement genuinely changes.

`docs/06-theory-library-roadmap.md` is the **roadmap** for the theory/documentation library (`SymbolsAndNomenclature`, `NinthDegreePolynomialTheory`, etc.) that will be produced incrementally — this is the working checklist for the conversational + production phases with the AI IDE.
